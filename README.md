# Space Grade Linux

Space Grade Linux (SGL) is an open source project developing a Yocto-based reference distribution for space systems. It is organized as Space Grade Linux a Series of LF Projects, LLC, governed by its [Technical Steering Committee](https://github.com/space-grade-linux/TSC) under the [Technical Charter](https://github.com/space-grade-linux/TSC/blob/main/CHARTER.md). Community discussion happens on the [mailing list](https://lists.elisa.tech/g/space-grade-linux), currently hosted by ELISA.
